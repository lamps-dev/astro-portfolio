# What is happening right now?

So, I woke up on the 21st, and went about my day, but then I saw a bunch of vulnerabilities happening at once.

This is honestly one of the most wild weeks/months EVER LIKE WHAT THE FUCK

The most notable security vulnerability though, is: **PHP2Shell**.

(Also thanks https://bsky.app/profile/nightshade.technology for documenting most of this :3)

## PHP2Shell

Apparently, you can exploit PHP when it runs out of memory (OOM error), it utilizes a low-level C function, and sometimes it may leave memory in an half-broken state, which leads to a remote code execution (RCE)

This is.. **VERY BAD** right now, because ~70% of the internet still runs on PHP.

The notable websites that went down were:

- DevianArt
- WiKirby
- Alpine Linux Wiki
- FOSS Wiki
- Mirahese
- Wiki.gg
- 4chan
