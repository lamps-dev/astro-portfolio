Two ways to put a video file in a post. Both use files served from this site —
no third-party embed, so nothing to consent-gate.

## 1. Markdown syntax

Exactly like an image, just pointing at a video file:

```markdown
![Random memes from discord part 11](/files/assets/videos/randomemesdiscordpart11.mp4)
```

![Random memes from discord part 11](/files/assets/videos/randomemesdiscordpart11.mp4)

-# The alt text becomes the accessible name. Good enough for most drops.

## 2. The Video component

For a visible caption, a poster frame, a reserved aspect ratio, or several
encodings:

```mdx
<Video
  src="/files/assets/videos/randomemesdiscordpart11.mp4"
  ratio="9/16"
  caption="Part 11 — vertical, so the ratio stops the page jumping while it loads."
/>
```

<Video
  src="/files/assets/videos/randomemesdiscordpart11.mp4"
  ratio="9/16"
  caption="Part 11 — vertical, so the ratio stops the page jumping while it loads."
/>
